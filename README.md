# Create Design 'N' Decor updated by Palm3
![Alt](/images/icon.png "icon)")

The best explanation is that this is a resource loader for Design 'N' Decor that uses those assets.

## Content
In *beta 1.0.0-hotfix1* this is fully implemented:
- Deepslate tiles/red tiles
- Ornate iron glass window/pane/grate (the casing thing)
- Industrial plating
- Large metal girder, beam, diagonal girder
- Zinc bricks/checker tiles
- Stone metal/colored stone metal
- Velevet blocks
- Dark metal set (stairs, slabs, plating...)
- Frontlights
- Metals floors (andesite, brass...)
- All stone variants



## Download
The mod is avaiable for 1.20.1 Forge on both CurseForge and Modrinth.
- [CurseForge](https://www.curseforge.com/minecraft/mc-mods/design-n-decor-recrafted)
- Modrinth: none for now (needs to be approved).

You'll also need Design 'N' Decor in order to install this mod.
- [CurseForge](https://www.curseforge.com/minecraft/mc-mods/create-design-n-decor)
- [Modrinth](https://modrinth.com/mod/create-design-n-decor)

Follow this table to know which version of Design 'N' Decor you need to install.
  
  | DnD Version   |      Mod Version      |
  |----------|:-------------:|
  | 1.0.0 |  1.21.1 - 2.1.0 |
  | 1.0.1 | 1.21.1 - 2.1.0  |

## Installation
1. Download this mod from the links above and download the correct Design 'N' Decor version.      
2. After that, you should have both DnD and this mod. Both the mods need to be put in the ```mods``` folder.
3. Then, simply load the game and you are good to go.

## FAQ
Q. Why are my textures and models broken?

A. Most probably you don't have the original Design 'N' Decor file in the mods folder, or it's the wrong one. Check the [installation](https://github.com/PalmeProg/Create-Design-N-Decor-to-1.20.1/edit/1.20.1-main/README.md#installation).


Q. Do i need to also install Design 'N' Decor?

A. Yes you need it, even if it's on NeoForge 1.21.1
